# 2026-10-12 工作日志

## 人工势场法（APF）航路规划交互网页

**任务来源**：用户提供 4 张课程幻灯片照片（引力场/斥力场公式、力与位置迭代、任务条件表、两组参数条件），要求做一个参数可调、势场可手动创建、航路动画演示，并复现至少 5 个 APF 常见缺陷与改进措施的网页。

**产出**（项目根目录 `index.html`）：
- `index.html` / `style.css` / `js/{config,apf,field,view,app}.js`
- 全部为经典 `<script>` 标签，无构建、无外网依赖，可直接双击 file:// 打开
- 风格：白底黑字、蓝色 `#0b5cd5` 点缀、`border-radius: 0` 强制方角

**关键算法结论（重要，可复用）**：
幻灯片斥力公式的三种实现变体在幻灯片任务（起(0,0)→终(100,100)，禁飞区(20,40)/(80,60) r=17.5）上的表现：
| 变体 | 条件1 长度(参考149.2545) | 条件2 长度(参考168.0207) |
| --- | --- | --- |
| 经典 Khatib（无目标项） | 146.31 (-1.97%) | 147.87 (-12.0%) 且条件2失效 |
| 边界距离 dⁿ（python 目录旧标定） | 151.79 (+1.70%) | 167.75，条件2 40000 步不收敛 |
| **到圆心距离 + ‖q−q_g‖ⁿ 目标因子（幻灯片原式）** | **150.43 (+0.79%)** | **169.08 (+0.63%)** |

→ 结论：**幻灯片原式（d = ‖q−q_obs‖，乘 ‖q−q_g‖ⁿ）才是最能复现参考航路长度且不发散的实现**，已作为网页默认公式。python 目录 `API算法详解.md` §10 的"边界距离"标定可据此改进。

**数值工程约束**（避免 1/d 爆炸）：`dMin = 0.35 km`、单步位移限幅 `v_max` 默认 3 km/步。
**局部极小逃逸**：`|F|<ε` 判据不可靠，改为「连续 N 步与目标距离不下降 → 注入垂直于引力方向的切向力，每 150 步翻转方向」。

**6 个缺陷场景（均经 node 数值标定，页面加载时实算）**：
1. 局部极小值（U 形墙）：残距 64.86 km 停滞 → 开切向逃逸后抵达，L=157.61 km
2. 目标不可达 GNRON：经典 Khatib 残距 3.23 km → 加目标因子后 0.50 km 抵达
3. 步长过大：航路 150.55 km / 7 次折返 / 间隔 −0.43 km → 限幅 0.5 km 后 106.09 km / 0 折返 / +2.13 km
4. 安全裕度不足：d_obs=16 < r=17.5 → 侵入 2.86 km（K_rep 加到 5×10⁵ 仍侵入 1.65 km）→ d_obs=30 安全
5. 动态障碍：迎面驶来 → 被一路顶回无法抵达 → 加相对速度避让项 K_v=60 后 L=153.41 km 抵达
6. 参数敏感：同图两组参数 169.08 vs 150.43 km（+12.4%）

**坑**：
- 无头浏览器截图时 `#fragment` 定位会因动态插入缺陷卡片而错位，改用 iframe 高度=内容高度 + 负 top 偏移分段截图。
- `--virtual-time-budget` 下 rAF 只触发少数几次，动画进度在截图里推进很慢（真实浏览器正常）。
